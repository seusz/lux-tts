AI范儿 · 产品拆解 Hermes 官方终于上了很多人期待的 Web UI。（Web 图形界面） 以前装完 Hermes 就只能盯着命令行，改个配置要去翻 YAML 文件，配个 API key 要找对 .env 的格式，不少人卡在这一步就放弃了。 现在有了可视化界面，上面这些都在浏览器里直接搞定。来逐个看看。 Status：系统一眼看清 图：Status 首页 首页三张卡片：Agent 版本和运行状态、Gateway 的 PID、当前活跃会话数。 下面列出所有接入的消息平台，飞书、微信、Webhook，各自显示连接状态和最后心跳时间。 打开三秒知道系统活没活着。信息量刚刚好，不多不少。 Sessions：历史会话一网打尽 图：Sessions 页面 所有历史会话列表，带标题、模型、消息数、工具调用次数、时间戳，还有来源平台图标，CLI、飞书、微信一眼分得清。 右上角有全文搜索，直接搜消息内容。 跨平台的对话记录终于汇聚到一个地方了。 Analytics：用了多少一目了然 图：Analytics 页面 30 天 token 用量、Cache Hit 率、估算费用、session 总数，还有每天的用量图表和按模型拆分的明细。可以切 7D / 30D / 90D 周期看。 我打开一看，这几天跑了 31.8M token，Cache Hit 19%。花了多少钱：$0.0000。（因为用的是套餐） Logs：日志不用再 SSH 图：Logs 页面 系统运行日志直接在浏览器里看，推荐非技术的同学多用用，出了问题先来这里查一眼，比到处找人问靠谱。 Cron：定时任务可视化 图：Cron 页面 定时任务的管理界面。以前要去配置文件里写 cron 表达式，现在在这里看得见、改得动。 Skills：想关哪个关哪个 图：Skills 页面 所有已安装的 skill 按分类列出，General、Apple、Creative、DevOps 等共 97 个。 每个分类右边有开关，可以整组启用或禁用，展开后也能单独操作某一个。 之前管理 skill 要手动编辑配置文件，现在点一下就行。 Config：等这个等了很久 图：Config 页面 这是整个 Web UI 里我最想要的东西。 左侧是分类导航，General、Agent、Terminal、Memory、Security、Browser、Voice 等共 15 个分类，覆盖 Hermes 的所有配置项。 右侧是表单，直接在输入框里改，改完按 Save。 以前改配置要手动编辑 ~/.hermes/config.yaml，格式写错了连报错都看不懂。现在表单填完按 Save，三秒搞定。 右上角还有导入、导出、YAML 直接查看的按钮，迁移配置、备份一键搞定。 Keys：API key 终于有地儿填了 图：Keys 页面 这也是之前很多朋友的痛点：API key 不知道去哪里填，改了 .env 文件又不生效，改来改去最后整个重装。 Keys 页把所有 provider 列出来了。每个旁边有"Get key"链接，直接跳去对应申请页面。 填进去，保存，立刻生效。活跃 session 自动拿到新 key，不用重启。 没有聊天界面，也不需要 顺便说一句：这个 Web UI 没有类似 OpenClaw 那样可以直接对话的聊天界面。不需要。 Hermes 本来就是接飞书、微信、CLI 用的，Web UI 的定位是管理工具，不是对话入口。各司其职。 另外，也没有中文，但我想应该过几天就会有的。 怎么用上这个Web UI 两步，执行： hermes update hermes dashboard update 先把版本更新到最新，dashboard 把 Web UI 跑起来，默认地址 127.0.0.1:9119，浏览器打开就行。有一说一，这估计是临时赶工出来的。咱就说，为什么不整成爱马仕那种高贵的配色？？？ 你现在是纯命令行还是已经跑起 Web UI 了？ Config 和 Keys 哪个对你帮助最大，评论区聊聊 觉得有用 → 点个  ❤️   在看  转给还不知道的朋友 点个赞 👍 告诉我你看完了 关注「AI范儿」，下次更新第一时间收到
