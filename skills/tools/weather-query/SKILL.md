# Weather Query 技能

## 功能描述

使用和风天气 API 查询任意城市的实时天气信息，支持：
- 实时天气查询
- 城市名称识别（支持中文、英文、拼音）
- 温度、湿度、风力、天气状况等信息
- 语音播报天气

## 配置要求

### 1. 获取和风天气 API Key

1. 访问 https://dev.qweather.com/
2. 注册账号并登录
3. 进入"控制台" → "我的应用"
4. 创建新应用，选择"免费套餐"（每月 1000 次免费调用）
5. 复制 API Key

### 2. 配置环境变量

在 `/opt/hermes/.env` 中添加：

```bash
# QWeather API Key - 和风天气 API
# Get at: https://dev.qweather.com/
QWEATHER_API_KEY=your_api_key_here
```

### 3. 重启 Docker 容器（如果使用 Docker）

```bash
docker restart hermes
```

## 使用方式

### 1. 查询实时天气

```
"查询南京的天气"
"北京今天天气怎么样"
"上海的实时温度"
```

### 2. 查询未来天气

```
"南京未来 3 天天气预报"
"北京周末天气如何"
"上海下周天气情况"
```

### 3. 语音播报天气

```
"播报南京的天气"
"用语音告诉我北京的天气"
```

## 返回信息

查询结果包含：
- 城市名称
- 实时温度
- 天气状况（晴、多云、雨等）
- 湿度
- 风力等级和方向
- 体感温度
- 更新时间

## API 说明

### 和风天气 API 免费套餐

- **每月调用次数**: 1000 次
- **支持城市**: 全球 200+ 国家和地区
- **数据更新**: 实时数据，每 10 分钟更新
- **城市编码**: 自动查询，无需手动查找

### 城市编码查询

如果知道城市编码，可以直接使用：
- 南京：101190101
- 北京：101010000
- 上海：101020000
- 广州：101280101

## 故障排查

### 问题 1: "API Key 无效"

**原因**: API Key 配置错误或未配置

**解决**:
1. 检查 `/opt/hermes/.env` 文件
2. 确认 QWEATHER_API_KEY 已正确填写
3. 重启 Docker 容器

### 问题 2: "找不到城市"

**原因**: 城市名称不支持或拼写错误

**解决**:
1. 使用标准中文城市名（如"南京"而非"南京市"）
2. 尝试使用城市编码
3. 访问和风天气官网查询城市编码

### 问题 3: "调用次数超限"

**原因**: 免费套餐每月 1000 次限制

**解决**:
1. 等待下个月重置
2. 升级到付费套餐
3. 减少查询频率
